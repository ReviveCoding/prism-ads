# Security Policy

## Reporting a vulnerability

Please report suspected vulnerabilities through GitHub's private vulnerability reporting feature
when it is available for this repository: open the **Security** tab, choose **Advisories**, and
select **Report a vulnerability**. Do not disclose sensitive security details in a public issue.

Use repository Issues only for non-sensitive bugs and reproducibility problems. Include the
affected version, a minimal reproduction, and expected versus observed behavior without attaching
credentials, private data, or third-party datasets.

This is research software rather than a production service. Reports will be assessed on a
best-effort basis, and no service-level response time is promised.
